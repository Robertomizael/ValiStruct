# Guía rápida para administradores

Antes de la beta:
- use HTTPS;
- configure autenticación;
- limite CORS;
- programe respaldos;
- ejecute self-test y E2E;
- revise incidencias;
- supervise `/monitor`;
- mantenga R/Python y paquetes actualizados;
- prefiera OIDC/SSO para producción institucional.
