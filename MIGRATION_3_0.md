# Migración de proyectos a formato 3.0

ValiStruct 3.0 agrega:
- `schemaVersion: "3.0"`
- `release`
- `preferences`

Los datos históricos de módulos 0.x–2.x se conservan sin reescribir sus estructuras.
Use el módulo de migración antes de reemplazar archivos originales.
Mantenga una copia de respaldo.
