# Revisión de seguridad — ValiStruct 3.0 RC1

## Debe verificarse antes de beta
- HTTPS en frontend/backend.
- CORS restringido.
- autenticación activa para biblioteca institucional.
- OIDC/SSO preferido en producción.
- archivos temporales eliminados.
- límites de carga configurados.
- backups cifrados o protegidos.
- telemetría desactivada por defecto.
- datos crudos excluidos de sincronización por defecto.
- restauración restringida a administradores.
- pruebas de path traversal en ZIP.
- pruebas de control de permisos.
- revisión de dependencias.

La revisión incluida es técnica preliminar y no sustituye una auditoría profesional independiente.
